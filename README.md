# QA 4기 최종 프로젝트

엘리스 LXP 플랫폼의 최종 프로젝트 QA 검증을 위한 저장소입니다.

이번 프로젝트는 학습자와 교육자 권한에서 핵심 API를 검증하고, 제공된 부하 테스트 로그를 분석하여 서비스 안정성과 개선 방향을 도출하는 것을 목표로 합니다.

## 주요 범위

- API 기능 테스트 자동화
- 권한별 테스트 시나리오 검증
- 부하 테스트 로그 분석
- 발견 이슈 및 개선안 정리

## 실행 준비

```bash
cd part1_api_automation
pip install -r requirements.txt
```
